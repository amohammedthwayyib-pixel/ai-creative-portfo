# Creative portfolio (Next.js + Tailwind + Framer Motion)
1. `npm install` then `npm run dev` → http://localhost:3000
2. Edit `src/data/site.ts`: name, email, socials, skills, tools and projects. All projects ship as labelled demos.
3. Add media in `public/` and set `image` / `video` on a project. Add your PDF at `public/resume.pdf`.
4. Push to GitHub, then import the repo on vercel.com (no environment variables needed).
